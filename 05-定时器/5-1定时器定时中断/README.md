# 5-1 定时器定时中断
> 用 TIM2 产生精确的周期性中断，每 100ms 触发一次。定时器是 STM32 的「心跳」，PWM、输入捕获、编码器全都建立在它之上。

---

## 学什么

- `TIM_TimeBaseInitTypeDef` 时基配置：预分频 PSC + 自动重装载 ARR
- **中断周期公式**：`T = (PSC+1) × (ARR+1) / 72MHz`
- TIM2 挂在 **APB1 总线**（最高 36MHz，但定时器时钟被 ×2 后仍是 72MHz）
- `TIM_ITConfig()` 使能更新中断 + `NVIC` 配置中断优先级

## 硬件连接

无外部模块，用 OLED 显示计数（SCL→PB8，SDA→PB9）

## 关键代码

本工程参数与计算：

```c
TIM_Prescaler = 7200 - 1;   // 预分频
TIM_Period    = 1000 - 1;   // 自动重装载
```

```
中断频率 = 72,000,000 / 7200 / 1000 = 10 Hz
中断周期 = 1 / 10 = 100 ms
```

改成 1 秒：把 `TIM_Period` 改为 `10000 - 1` 即可。

## 注意与踩坑

- ⚠️ **注意：`Num` 被加了两次。**

`main.c` 的 `while(1)` 里有 `Num++`，定时器中断里也有 `Num++`。
所以屏幕上的数字涨得比预期快得多 —— 主循环每转一圈就 +1，而中断每 100ms 才 +1。

**如果想让 `Num` 表示「中断次数」，把 `main.c` 里那句 `Num++` 删掉。**
- 中断服务函数写在 `hardware/Timer.c` 的 `TIM2_IRQHandler()` 里（不在 `stm32f10x_it.c`，那个还是官方模板）
