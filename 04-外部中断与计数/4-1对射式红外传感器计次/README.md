# 4-1 对射式红外传感器计次
> 物体遮挡红外对射传感器时计数值自动 +1，OLED 实时显示。第一次接触「中断」——芯片不再傻等，而是被事件主动唤醒。

---

## 学什么

- **EXTI 外部中断**：引脚电平变化瞬间触发中断，无需主循环轮询
- `AFIO` 时钟 —— 配置外部中断前必须先开 AFIO 时钟（`RCC_APB2Periph_AFIO`）
- `GPIO_EXTILineConfig()` 把具体引脚映射到中断线
- 中断服务函数 `EXTI15_10_IRQHandler` 里必须 `EXTI_ClearITPendingBit()` 清标志位，否则会无限触发

## 硬件连接

传感器 DO → PB14（对射式红外：一端发射，一端接收，中间有物体遮挡时输出变化）

## 关键代码

```c
OLED_ShowString(1, 1, "count:");
while (1)
{
    OLED_ShowNum(1, 7, CountSensor_Get(), 5);
}
```

主循环里只有一句显示，**计数全在中断里完成** —— 这就是中断的意义：主循环可以干别的，事件来了硬件自动通知。

## 注意与踩坑

- **中断服务函数里不能写 `Delay_ms()` 和耗时操作**，否则会阻塞其他中断。中断函数要「快进快出」
- 计数用主循环轮询也能做，但快速遮挡时会漏计 —— 这正是要用中断的原因
