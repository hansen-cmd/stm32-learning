# 4-2 旋转编码器计次
> 顺时针旋转编码器数值增加，逆时针减少。学习正交编码器（A/B 两相）的方向判别。

---

## 学什么

- **正交信号**：A、B 两相输出相位差 90° 的方波，靠「谁先变」判断方向
- 判向方法：A 相触发中断时读 B 相电平 —— B 为低则正转，B 为高则反转（或相反，取决于接线）
- `int16_t` 有符号计数，可以往负数方向减
- `OLED_ShowSignedNum()` 显示带符号数值

## 硬件连接

A 相 → PB1 ／ B 相 → PB0（编码器另有 VCC、GND）

## 关键代码

```c
Num += xuansensor_Get();          // 增量累加，可为负
OLED_ShowSignedNum(1, 5, Num, 5);
```

`xuansensor_Get()` 返回 **+1 或 -1**（每次转动的增量），主循环把它累加到总数上。

## 注意与踩坑

- 这个是**软件方式**解码（靠中断 + 读另一相电平），转动很快时可能漏步
- 更可靠的方式是用定时器的硬件编码器接口 —— 见 `4-4` 和 `6-6`
