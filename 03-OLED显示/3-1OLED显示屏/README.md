# 3-1 OLED 显示屏
> 在 0.96 寸 OLED 上显示字符、字符串、十进制数、有符号数、十六进制和二进制。从此单片机有了「屏幕」，调试再也不用靠猜。

---

## 学什么

- **软件模拟 I2C**：用两个 GPIO 手动翻转电平模拟 I2C 时序（见 `OLED.c` 开头的宏定义）
- `OLED_Font.h` 字库 —— 每个字符对应一组点阵数据，显示就是把点阵写进显存
- `OLED_ShowXxx()` 系列函数：字符/字符串/无符号数/有符号数/十六进制/二进制
- 坐标体系：`(行, 列)`，行 1~4，列 1~16

## 硬件连接

SCL → PB8 ／ SDA → PB9（4 针 OLED：VCC、GND、SCL、SDA）

## 关键代码

```c
OLED_Init();
OLED_ShowChar(1, 1, 'A');            // 第1行第1列 显示字符
OLED_ShowString(1, 3, "yhs");        // 字符串
OLED_ShowNum(2, 1, 12345, 5);        // 数字，5 = 显示宽度
OLED_ShowSignedNum(2, 7, -66, 2);    // 有符号数（带负号）
OLED_ShowHexNum(3, 1, 0x55, 2);      // 十六进制
OLED_ShowBinNum(3, 4, 0x55, 8);      // 二进制
```

**数字显示的长度参数**：`12345` 长度为 5，若写 3 则只显示后 3 位 `345`。位数不够时可用前导零补位。

## 注意与踩坑

- 这个项目是后续所有实验的「调试显示器」，后面每个项目基本都用 OLED 看数据
- 如果屏幕不亮，先检查 I2C 地址（常见 0x78 / 0x7A）和接线
