# STM32F103 入门实验合集

> 硬件平台：**STM32F103C8T6**（最小系统板 / "蓝丸"）
> 开发工具：**Keil uVision5 + ARMCC**，使用 **STM32 标准外设库（StdPeriph）**
> 学习路线：跟 B 站江协科技（江科大）STM32 教程，从 GPIO 点灯一路做到 PWM 电机控制

这是我从零开始学 STM32 的完整练习记录。每个项目都是**可直接打开编译的完整 Keil 工程**，
不是代码片段——点开就能烧录运行。

**每个项目文件夹内部**（以 6-1 为例）：

| 文件夹 | 里面是什么 | 要不要看 |
|---|---|---|
| `user/` | `main.c` —— **主程序入口，看代码先看这里** | ✅ 重点 |
| `hardware/` | 自己写的外设驱动（LED/按键/OLED/PWM…） | ✅ 重点 |
| `delay/` | 延时函数 | 次要 |
| `start/` | 启动文件 + 内核寄存器定义（官方给的） | 不用看 |
| `library/` | STM32 标准外设库（官方给的） | 不用看 |
| `*.uvprojx` | **Keil 工程文件，双击它打开** | ✅ |
| `Objects/`、`Listings/` | 编译产物（已用 .gitignore 排除，不上传） | 忽略 |

一句话：**看代码只看 `user/main.c` 和 `hardware/`**，其余是环境和库文件。

## 怎么用这些工程

1. 装好 **Keil uVision5** 并安装 STM32F1 的 Device Family Pack
2. 进入任意项目文件夹，**双击 `.uvprojx` 文件**（不是文件夹）
3. 点 `Rebuild` 编译 → 用 ST-Link 烧录
4. 若编译报找不到头文件，检查 Keil 的 `Options for Target → C/C++ → Include Paths`

> ⚠️ 仓库里**不含编译产物**（`Objects/` 等已排除）。第一次打开需要重新编译一次，
> 这是正常的，也让仓库从 400MB 瘦到了几十 MB。

## 几个历史遗留问题（我自己踩的坑，留个记号）

| 位置 | 问题 | 说明 |
|---|---|---|
| `2-1按键控制led/` | 主文件叫 **`mani.c`** | 拼错了，本应是 `main.c`。**没改**是因为 Keil 工程文件里记录着文件名，改名会导致工程打不开 |
| `2-2光敏传感器控制蜂鸣器/` | 有 **`MAIN.c`** 和 **`mian.c`** 两个文件 | 工程实际编译的是 `MAIN.c`；`mian.c` 是废弃副本，可忽略 |
| `2-2` 的 `MAIN.c` | `LightSensor_Init()` 被注释掉了 | 但代码里仍在读该引脚。想让光敏真正工作，需要把那行注释放开 |
| `1-1led闪烁流水灯/` | 有 `led.uvprojx` 和 `点灯.uvprojx` 两个工程 | 内容相同，任选一个打开 |
| `6-2`、`6-4`、`6-6` | 残留 `6-1PWM驱动.*` 的配置 | 复制工程时带过来的垃圾，以**本文件夹名的那个** `.uvprojx` 为准 |

## 在 GitHub 上怎么查代码

详见同目录下的 **[GitHub使用指南.md](GitHub使用指南.md)**。这里列几个最快的操作：

| 我想… | 怎么做 |
|---|---|
| 找某个函数在哪用的（比如 `PWM_SetCompare1`） | 仓库页面顶部搜索框输入函数名，回车 → 点 "Code" 结果 |
| 浏览某个项目 | 首页点文件夹 → 一直点到项目 → 页面下方自动显示该目录的 README |
| 看代码改动历史 | 点文件页右上角 **History**，或点某一行的行号看 Blame |
| 下载全部代码 | 绿色 **Code** 按钮 → **Download ZIP** |
| 把代码拉回本地继续改 | `git clone` 仓库地址（详见指南） |
