# 6-6 编码器测速
> 用 TIM3 的编码器接口模式读取旋转编码器的计数值，OLED 显示。用「定时读 CNT 并清零」的方式换算成速度。

---

## 学什么

- **编码器接口模式**：定时器变成由外部脉冲驱动的计数器，硬件自动判向，CPU 零开销
- `TIM_EncoderMode_TI12` —— A、B 两相都计数，4 倍频（转一圈的计数值 = 格数 × 4）
- **测速原理**：固定间隔（如 100ms）读一次 CNT 并清零，读到的增量就是这段时间转过的量
- PA6/PA7 对应 TIM3 的 CH1/CH2，无需额外中断

## 硬件连接

编码器 A、B 相 → PA6、PA7（另接 VCC、GND）

## 关键代码

```c
Encoder_Init();
OLED_ShowString(1, 1, "NUM:");
while (1)
{
    OLED_ShowNum(1, 6, encoder_Get(), 5);
}
```

这里显示的是**累计计数值**。要做成「速度」，需要在定时器中断里定时读取 CNT 后清零：
```c
Speed = TIM_GetCounter(TIM3);   // 读
TIM_SetCounter(TIM3, 0);        // 清零
```

两次读取的间隔就是测速周期。

## 注意与踩坑

- 编码器接口模式**不需要配置 EXTI 中断**，硬件自动处理，比 4-2 的软件方式可靠得多
- CNT 是 16 位寄存器，超过 65535 会溢出回绕。长时间计数要注意处理溢出，或定时清零
- 本文件夹残留 `6-1PWM驱动` 配置，以 `6-6旋转编码器接口测速.uvprojx` 为准
