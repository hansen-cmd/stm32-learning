# 6-5 PWMI 模式测频率 + 占空比
> 用定时器的 PWMI 模式一次性同时测出频率和占空比，并自动在 1k/2k/5k/10k Hz 四档间循环切换来验证。带 LED 运行指示和信号诊断。

---

## 学什么

- **PWMI 模式**：一个通道测周期（CCR1），另一个通道测高电平宽度（CCR2），一次测两个参数
- 占空比公式：`Duty = CCR2 / CCR1`
- `TIM_PWMIConfig()` 一行配置即可进入 PWMI 模式
- **自诊断设计**：主动探测 PA7 电平是否翻转，区分「没信号」和「算错了」
- 板载 LED（PC13）翻转指示程序在跑 —— 一眼区分「程序没烧进去」和「测量有问题」

## 硬件连接

PWM 输出 → PA1 ／ 输入捕获 → PA7（**两者要用杜邦线连接**）
板载 LED → PC13

## 关键代码

屏幕四行：

| 行 | 含义 |
|:--:|---|
| 1 | `Freq Meter` 标题 |
| 2 | `F:` 测得的频率（Hz） |
| 3 | `D:` 测得的占空比（%） |
| 4 | `P7:` 信号诊断 —— `JUMP`= 收到方波 / `STAT` = 电平静止 |

程序每 1.5 秒切换一次输出频率（1000 → 2000 → 5000 → 10000 Hz），屏幕上 `F:` 应该跟着变。

**第 4 行的诊断很实用**：
- 显示 `STAT` → PA1 没输出 或 跳线没连通，先查硬件
- 显示 `JUMP` 但 `F:` 不对 → 硬件没问题，查捕获配置
