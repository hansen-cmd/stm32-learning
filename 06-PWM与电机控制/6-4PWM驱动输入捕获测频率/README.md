# 6-4 输入捕获测频率
> 自己用 PA1 输出一路 PWM，再用 PA7 输入捕获测回来，验证测量是否准确。输入捕获是「测量外部信号」的基础技能。

---

## 学什么

- **输入捕获**：信号边沿到来时，硬件自动把当前计数值锁存到 CCR 寄存器
- **测周法**：`Freq = 72MHz / (PSC+1) / CCR` —— 数两个上升沿之间经过了多少个时钟周期
- `TIM_ICInit()` 配置捕获通道、边沿、分频、滤波
- `PWM_SetPrescaler()` 动态改变输出频率，方便验证不同频率下的测量精度

## 硬件连接

PWM 输出 → PA1（TIM2_CH2）
输入捕获 → PA7（TIM3_CH2）
**PA1 与 PA7 要用杜邦线连起来**

## 关键代码

```c
PWM_SetCompare2(50);          // 占空比 = CCR / 100
PWM_SetPrescaler(720 - 1);    // Freq = 72M / (PSC+1) / (ARR+1)
while (1)
{
    OLED_ShowNum(1, 6, IC_Get(), 5);
}
```

屏幕上显示的应该接近你用公式算出的 PWM 频率。两者对得上，说明捕获配置正确。

## 注意与踩坑

- **最常见的坑：忘记用导线把 PA1 和 PA7 连起来。** 没信号输入时捕获值会是 0 或乱跳
- 测高频用测频法（数固定时间内的脉冲数），测低频用测周法（本例）。本例 PSC=720 适合测 kHz 级信号
- 本文件夹残留 `6-1PWM驱动` 配置，以 `6-4PWM驱动输入捕获测频率.uvprojx` 为准
