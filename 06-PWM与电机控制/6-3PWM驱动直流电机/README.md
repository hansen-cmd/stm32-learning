# 6-3 PWM 驱动直流电机
> 设置速度值 30，直流电机按该速度持续转动。学习 H 桥驱动的方向控制 + PWM 调速组合。

---

## 学什么

- **直流电机不能直接接单片机**：需要 H 桥驱动模块（TB6612 / L298N / DRV8833）
- **方向控制**：两个 GPIO 一高一低 = 正转，反过来 = 反转，都低 = 刹车，都高 = 滑行
- **速度控制**：PWM 占空比越大，平均电压越高，转速越快
- `dianji_SetSpeed()` 把速度值映射为 CCR，正值正转、负值反转

## 硬件连接

方向控制 → PA4、PA5 ／ PWM 速度 → 驱动模块 PWM 输入
电机通过驱动模块独立供电

## 关键代码

```c
dianji_Init();
dianji_SetSpeed(30);      // 速度 30（正值 = 正转）
```

若传入负数则反转，例如 `dianji_SetSpeed(-30)`。

**注意**：直流电机在占空比很低时可能不转（静摩擦力），需要给一个启动占空比。

## 注意与踩坑

- 电机是**感性负载**，务必在驱动模块电源端并联电容，并加续流二极管保护
- 电机和单片机**必须共地**，否则 PWM 信号没有参考电平
- 本文件夹残留 `6-1PWM驱动` 配置，以 `6-3PWM驱动直流电机.uvprojx` 为准
