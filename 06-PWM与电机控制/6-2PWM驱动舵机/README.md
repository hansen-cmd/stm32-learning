# 6-2 PWM 驱动舵机
> 每按一次按键，舵机转动 60°，在 0° → 60° → 120° → 180° 之间循环，OLED 显示当前角度。

---

## 学什么

- **舵机不是靠占空比，是靠脉宽**：周期固定 20ms（50Hz），高电平持续 0.5ms~2.5ms 对应 0°~180°
- 角度 → CCR 的线性映射：`CCR = Angle / 180 × 2000 + 500`（对应 0.5ms~2.5ms）
- 按键状态机：每次触发角度 +60，超过 180 归零
- `duoji_SetAngle()` 把物理量（角度）和寄存器值（CCR）解耦，主程序不用关心底层

## 硬件连接

舵机信号线 → PWM 输出引脚 ／ 按键 → PB1
舵机单独供电（5V），**务必与单片机共地**

## 关键代码

```c
KeyNum = Key_GetNum();
if (KeyNum == 1)
{
    Angle += 60;
    if (Angle > 180) { Angle = 0; }
    duoji_SetAngle(Angle);
    OLED_ShowNum(1, 7, Angle, 3);
}
```

**舵机控制的本质**：给一个周期 20ms、高电平宽度在 0.5~2.5ms 之间的方波。舵机内部电路根据脉宽决定转到哪个角度并保持。

## 注意与踩坑

- 舵机**必须用外部 5V 供电**，不要直接从单片机取电 —— 舵机堵转电流可达几百 mA，会拉垮系统电源甚至烧芯片
- 接线：棕色=GND，红色=VCC(5V)，橙色=信号线
- 本文件夹残留了 `6-1PWM驱动.*` 的配置文件，是复制工程时带过来的，**请以 `6-2PWM驱动舵机.uvprojx` 为准**
