# 2-2 光敏传感器控制蜂鸣器
> 光线被遮挡（变暗）时蜂鸣器报警，光线充足时静音。一个完整的「传感器输入 → 逻辑判断 → 执行器输出」闭环。

---

## 学什么

- 数字量传感器读取：传感器模块内部已做比较器，直接输出 0/1
- 模块化驱动：`Buzzer.h`（执行器）+ `LightSensor.h`（传感器），主程序只写业务逻辑
- `if/else` 条件控制 —— 把输入状态映射到输出动作

## 硬件连接

光敏传感器 DO → PB14 ／ 蜂鸣器 → PB12

## 关键代码

```c
if (LightSensor() == 1)   // 1 = 光线暗
{
    Buzzer_ON();
}
else
{
    Buzzer_OFF();
}
```

光敏模块上通常有个**可调电位器**，用来设定触发阈值（调到什么程度算「暗」）。

## 注意与踩坑

- ⚠️ **已知 bug：`MAIN.c` 里 `LightSensor_Init()` 被注释掉了**，但代码仍在读该引脚。

未初始化的 GPIO 读到的值不可靠，光敏可能不工作。**把第 9 行的注释去掉**即可修复：
```c
LightSensor_Init();   // 取消这行的注释
```
- 本文件夹有 **`MAIN.c`** 和 **`mian.c`** 两个文件，工程实际编译的是 `MAIN.c`；`mian.c` 是废弃副本，可忽略
