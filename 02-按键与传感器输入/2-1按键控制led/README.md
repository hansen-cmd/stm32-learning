# 2-1 按键控制 LED
> 两个按键分别控制两颗 LED：按 1 号键翻转 LED1，按 2 号键翻转 LED2。从这里开始学习「输入」和模块化封装。

---

## 学什么

- `GPIO_Mode_IPU` 上拉输入 —— 按键未按下时引脚被内部电阻拉高，按下接地变低电平
- **按键消抖**：检测到按下后 `while` 死等松手，避开机械抖动产生的多次触发
- `Key_GetNum()` 返回按键编号 —— 把硬件细节封装成函数，主程序只看「几号键」
- `.h` / `.c` 分离：头文件声明接口，源文件实现细节

## 硬件连接

LED：PA1、PA2 ／ 按键：PB1、PB11（按键另一端接地）

## 关键代码

```c
KeyNum = Key_GetNum();
if (KeyNum == 1) { LED1_Turn(); }   // 翻转 = 亮变灭、灭变亮
if (KeyNum == 2) { LED2_Turn(); }
```

`LED_Turn()` 的实现思路（见 `hardware/led.c`）：读取当前输出电平，再写入相反的电平。

## 注意与踩坑

- ⚠️ **主文件叫 `mani.c`，是 `main.c` 的拼写错误。**

没有改名是因为 Keil 的 `.uvprojx` 工程文件里记录着文件名，直接改名会导致工程打不开。想改名的话，需要同时在 Keil 里移除旧文件、添加新文件后重新保存工程。
