# 1-1 LED闪烁流水灯
> 让 PA0~PA7 八个引脚依次点亮，形成来回流动的流水灯。STM32 的第一个程序：学会让芯片输出高低电平。

---

## 学什么

- `RCC_APB2PeriphClockCmd()` —— 开 GPIO 时钟（**STM32 任何外设用之前都必须先开时钟**，最容易忘的一步）
- `GPIO_InitTypeDef` 配置结构体：模式、引脚、速度三件套
- `GPIO_Mode_Out_PP` 推挽输出 —— 能主动输出高/低电平，驱动能力最强
- `GPIO_Write()` 一次性写整个 16 位端口，比逐个引脚操作更高效

## 硬件连接

PA0 ~ PA7 各接一个 LED（串联 220Ω~1kΩ 限流电阻）

## 关键代码

```c
GPIO_Write(GPIOA, ~0x0001);   // 0000 0000 0000 0001
Delay_ms(500);
GPIO_Write(GPIOA, ~0x0002);   // 0000 0000 0000 0010
```

**为什么有个 `~` 取反？** 因为 LED 是**低电平点亮**（共阳接法：LED 正极接 VCC，负极接 GPIO）。
写 `0x0001` 会让 PA0 输出高电平 → LED 灭；取反后 PA0 变低电平 → LED 亮。
如果你的 LED 是高电平点亮（负极接地），把 `~` 去掉即可。
