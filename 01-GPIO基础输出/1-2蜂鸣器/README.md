# 1-2 蜂鸣器
> PB12 每 500ms 翻转一次电平，驱动蜂鸣器间歇鸣响。练习单个引脚的精确控制。

---

## 学什么

- `GPIO_WriteBit()` —— 只操作一个引脚，不影响同端口其他引脚
- `Bit_SET` / `Bit_RESET` 两个枚举值设置高低电平
- `GPIO_Pin_12` 位掩码写法：每个引脚对应一个 bit，可用 `|` 同时选多个

## 硬件连接

PB12 → 蜂鸣器模块信号脚（VCC 接 3.3V/5V，GND 共地）

## 关键代码

```c
GPIO_WriteBit(GPIOB, GPIO_Pin_12, Bit_RESET);
Delay_ms(500);
GPIO_WriteBit(GPIOB, GPIO_Pin_12, Bit_SET);
Delay_ms(500);
```

这里产生的是 **1Hz 的方波**（周期 1 秒）。

## 注意与踩坑

- **有源蜂鸣器**：内部带振荡源，给电平就响（本例用法）
**无源蜂鸣器**：相当于小喇叭，必须给 PWM 方波才会响，且频率决定音调

买模块时注意区分，两者的驱动代码完全不同
